# **Prompt for Vibe Coding**

# **NotebookLM-Style UI (with Spaces Sidebar, Notes, and Enhanced Studio)**

**Objective:**

Build a workspace-driven NotebookLM-style app with a **sidebar at the very left** for managing spaces, and three main panels inside each space: Sources (with Notes), Chat, and Studio (Tools, Tasks, Virtual Employees).

---

## **Layout & Style**

- **Sidebar (left edge):** Existing sidebar with Spaces option. It gets contracted when one space is selected
- **Main screen (to the right of sidebar):** Split into three panels:
    1. **Sources Panel (Left)** – workspace header + sources/notes.
    2. **Chat Panel (Center)** – conversational UI.
    3. **Studio Panel (Right)** – Tools, Tasks, Virtual Employees.
- Minimalist design, rounded corners, subtle shadows.
- Inline editing, hover effects, smooth transitions.

---

## **Functional Blocks**

### **1. Sidebar – Spaces Management**

- Section title: **Spaces** (always pinned).
- **Default spaces:**
    - **My Personal Space**
    - **My Workspace**
- **User-created spaces:** additional spaces can be added with “+ Add Space.”
- When the main option spaces is clicked, it must show a screen with all **Space cards** showing:
    - Default icon (editable later).
    - Space name.
    - Resource count (Sources + Notes + KB items).
- **Expand/Contract behavior:**
    - By default, it shows the available spaces
    - Clicking on the space opens the space view

---

### **2. Sources Panel (Left, inside each space)**

**A. Workspace Header**

- Editable cover image.
- Editable workspace name.
- Editable description (multi-line).

**B. Tabs:**

1. **Knowledge Base**
    - “+ Add source” button → upload source.
    - “Discover” button → enables the user to look for resources with the chatbox.
    - Sources appear items (icon + title) with the option to include them in the knowledge base + the option to include all sources at the top
    - Empty state: “Saved sources will appear here. Click Add to upload PDFs, websites, text, videos, or audio files. Or import directly from Google Drive.”
2. **Notes**
    - “+ Add Note” → opens rich text/markdown editor.
    - Notes listed with title + preview.
    - Each note has “Add to Knowledge Base” toggle.
    - Search + browse capability.
    - Notes flagged as KB are merged with Sources for AI context.
    - When selected, the note details will be shown in the chat panel

---

### **3. Chat Panel (Center)**

- Empty state: “Upload a source to get started.”
- Input at bottom: Chatbox from the main menu
- Chat leverages **Sources + Notes (KB items)** as context.
- Messages displayed in threaded conversation.
- Option to **save a chat message as a Note.**

---

### **4. Studio Panel (Right, divided into 3 subsections)**

**A. Tools**

- Default quick actions: “Audio Summary,” “Video Summary,” “Mind Map,” “Reports.”
- “+ Add Tool” button to configure a new tool.
- Displayed as grid of cards.

**B. Tasks**

- Tasks added manually or auto-generated by tools.
- Empty state: “No tasks yet. Add a new one to get started.”
- “+ Add Task” button.
- Tasks shown as checklist with expandable details + status badges.

**C. Virtual Employees**

- Default: **Sophia – Executive Assistant.**
- “+ Add Employee” button → create new persona (name, role, avatar, assigned tools).
- Employees shown as profile cards with role + active tools.

---

## **Interactions**

- **Sidebar navigation:** Spaces can expand/contract to reveal subsections. Selecting a subsection changes the main panel view.
- **Editing workspace header:** Updates space identity (image, name, description).
- **Notes:** Can be created manually or saved from chat, marked as KB, searchable.
- **Tools → Tasks → Employees:** Workflow where tools create outputs → saved as tasks → assignable to employees.
- **Knowledge Base:** Composed of Sources + Notes flagged as KB, powering Chat + Studio.

---

## **Extra polish**

- Inline editing with autosave.
- Drag-and-drop reordering of sources and notes.
- Smooth expand/collapse for spaces and studio subsections.
- Consistent icon system (Lucide/Material).
- Light/dark mode toggle.

---

⚡ This way, the **Spaces feature lives in the main sidebar (above everything else)**, with expandable cards that reveal Sources, Notes, Chat, and Studio for each space.
