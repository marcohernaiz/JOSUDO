AI Assistant Platform MVP - Refined Development Prompt
🎯 Core Vision
Build a B2B2C AI assistant platform that acts as a smart middleware - users bring their own AI accounts and storage, we provide the unified interface and routing logic. Think "Zapier for AI models" with integrated cloud storage.
🏗️ Technical Architecture
Stack Requirements

Backend: Node.js + Express.js
Database: PostgreSQL (metadata only)
Frontend: React + Tailwind CSS
Authentication: OAuth 2.0 (Google primary)
Deployment: Docker containers ready

Core Services (Microservices Pattern)

Auth Service - Google OAuth + session management
Integration Service - AI model & cloud storage connections
Routing Service - Smart AI request routing
Billing Service - Usage tracking & subscription management
Storage Service - External cloud storage operations

💰 Billing Logic (Simplified)
Revenue Model

Base: $9.99/month platform fee
Premium Routing: Free (uses user's accounts)
Standard Routing: Deducted from monthly balance
Overages: Pay-per-use above $9.99

Implementation
javascript// Pseudo-code for billing logic
if (user.hasLinkedPremiumAccount(modelType)) {
  routeToUserAccount(request, user.credentials);
} else {
  const cost = calculateAPIcost(request);
  if (user.monthlyBalance >= cost) {
    routeToOurAPI(request);
    deductFromBalance(user.id, cost);
  } else {
    showTopUpPrompt();
  }
}
🔗 B2B2C API Design
Core Endpoints
POST /api/chat - Send message to AI
GET /api/chat/sessions - Get user's chat history
POST /api/chat/sessions - Create new chat session
DELETE /api/chat/sessions/:id - Delete chat session
GET /api/models - List available models
POST /api/integrations - Link new service
GET /api/usage - Get usage statistics
POST /api/billing/topup - Add funds
Partner Integration

Single API key per partner
End-user authentication handled by us
Partner never stores user data
Revenue sharing on subscription fees
