# JOSUDO.AI — Vibe Coding Tool PRD

Version: 1.0

Author: Marco Hernáiz / Sofía (AI)

Date: 15 Aug 2025

# 1\. Purpose

Build an MVP of the JOSUDO.AI “Virtual Employee” onboarding and interaction platform using a Vibe Coding approach (low-code $^ +$ prompt-driven UI building). The MVP should allow users to:

1. Pick a pre-defined virtual employee persona.
2. Customize role focus & work style.
3. Connect basic tools (optional at launch).
4. Have a first conversation with the AI.
5. See a simple dashboard with initial actions.

# 2\. Goals & Success Metrics

# Primary Goal:

Let new users create and start interacting with their first virtual employee within 10 minutes of signing up.

# MVP Success Metrics:

Activation rate: $80 %$ of sign-ups complete the “Hire Your Employee” flow. First task execution: $70 %$ of users request their employee to perform a task on day 1. Retention: $50 %$ of users return within 48 hours to interact again.

# 3\. Scope

# 3.1 In-Scope (MVP)

# 1\. Persona Selection UI

○ 7 predefined personas (The Closer, Connector, Guardian, Bridge, Visionary, Analyst, Innovator)

○ Card layout with name, tagline, skills, “Hire Me” button.

# 2\. Role Customization

○ Checkbox-based task focus.

○ Work style selector (Formal/Friendly/Casual/Enthusiastic).

○ Working hours (Always-on / Business hours / Custom).

# 3\. Tool Integration (Optional for MVP)

○ Google Calendar (read/write).

○ Gmail (read/send).

○ Slack (send messages).

○ OAuth-based connection.

# 4\. First Conversation Module

AI greets user, asks about company $&$ goals. ○ Summarizes understanding $&$ proposes Day 1 plan.

# 5\. Basic Dashboard

○ Today’s Tasks (from AI plan or user requests).

○ Recent Activity.

○ “Ask Me Anything” input.

# 6\. AI Backend

○ Role-specific prompt templates per persona.

○ Context memory per user (company, preferences, tasks).

○ Support for chat $^ +$ structured outputs (task lists, summaries).

# 3.2 Out of Scope (MVP)

Multi-employee management.

Advanced automations (cross-tool workflows).

Voice/video avatars.

Payments/billing.

Advanced analytics.

# 4\. User Flow

1. Sign Up / Log In
2. Persona Selection
3. Role Customization
4. Optional Tool Integration
5. First Conversation
6. Dashboard Access
7. Task Execution & Feedback Loop

# 5\. Functional Requirements

# 5.1 Persona Selection

FR-1: Display 7 persona cards with consistent layout.

FR-2: Clicking “Hire Me” triggers customization modal.

# 5.2 Role Customization

FR-3: Task focus is multi-select.

FR-4: Work style is single-select dropdown.

FR-5: Working hours can be pre-set or custom via time picker.

# 5.3 Tool Integration

FR-6: Integrations must use secure OAuth flow.

FR-7: If skipped, app still functions with basic AI tasks.

# 5.4 First Conversation

FR-8: Persona uses tailored greeting script.

FR-9: Must capture and store: ○ Company name ○ User’s role ○ Main goals

FR-10: Generate Day 1 action plan as structured list.

# 5.5 Dashboard

FR-11: List of today’s tasks with status markers.

FR-12: Activity feed for last 7 days.

FR-13: Free text input for AI requests.

FR-14: “Add Task” button that sends structured request to AI.

# 7\. Tech Stack (Suggested for Vibe Coding MVP)

Frontend: React $^ +$ Tailwind (for fast iteration).

Backend: Node.js $^ +$ Express.

Database: PostgreSQL (user data) $^ +$ Redis (session/context cache).

AI Integration: OpenAI API (gpt-4o or gpt-5 when stable).

Auth: Firebase Authentication or Auth0.

Hosting: Vercel (frontend) $^ +$ Render/Heroku (backend).

# 9\. Risks & Mitigations

Risk: Users may feel onboarding is too abstract without real examples. ○ Mitigation: Use sample conversation snippets & pre-filled task templates in onboarding.

Risk: Tool integrations may delay launch. ○ Mitigation: Make integrations optional in MVP.

Risk: AI responses too generic. ○ Mitigation: Create tailored prompt templates for each persona.
